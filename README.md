# 👻 Ghost of Code

Ghost of Code is an AI-powered spooky story generator built using Python, Flask, and Ollama.

## Features

- Generate spooky stories using AI.
- Customize stories using topic, setting, and mood.
- Save generated stories as Markdown files.
- View saved stories in a library.
- Search saved stories.
- Read saved stories.
- Delete unwanted stories.

## Technologies Used

- Python
- Flask
- Ollama
- Gemma 3 (1B)
- HTML
- CSS
- JavaScript
- Markdown

## Installation

1. Clone this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Install Ollama from https://ollama.com/
4. Download the model:

   `ollama pull gemma3:1b`

5. Start Ollama.
6. Run the application:

   `python app.py`

7. Open http://127.0.0.1:5000 in your browser.
